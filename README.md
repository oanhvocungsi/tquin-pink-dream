## 💎 Art Direction & Design System

- **Palette**: Dominant luxury pink spectrum — Baby Pink (`#FFD6E5`), Blush Pink (`#FFA6C9`), Electric Hot Pink (`#EC4899`), Rose Noir (`#240715`), and Pearl White highlights (`#FFF5F8`).
- **Typography**: 
  - **Syne** for oversized editorial headlines, magazine hero title cards, and dramatic presence.
  - **Outfit** for ultra-clean modern body typography and interface metadata.
  - **Cormorant Garamond (Italic)** for subtle, elegant fashion notes and script flairs.
- **Surfaces**: Frosted glassmorphism (`backdrop-filter: blur(20px)`), delicate hairline borders (`rgba(255, 182, 193, 0.4)`), and film noise grain texture (`<feTurbulence>` SVG filter).
- **Visuals**: Multi-layered interactive HTML5 Canvas with glowing pink orbs, 4-point diamond sparkle stars, and 3D fluttering petals that react to mouse proximity on desktop and float with restrained grace on mobile.

## 🎵 Royalty-Free Audio & SFX Engine
- **Soundtrack**: Procedural Web Audio API synthesizer that generates warm, viral TikTok dreamy pop chord progressions (Fmaj7 - Dm9 - Bbmaj7 - Cadd9) and bell arpeggios in any browser with zero external network dependencies.
- **Sound FX**: Tactile glass click, transition whoosh, crystal sparkle chimes, and gift fanfare.
- **Strict User Privacy**: No audio playback occurs before the user explicitly interacts by clicking "Unveil".
- **Visualizer**: Real-time animated audio equalizer bars with instant Mute/Unmute toggle.

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8 (`base: '/tquin-pink-dream/'`)
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) + Custom Glassmorphism
- **Motion**: Framer Motion 14 + Custom CapCut Easing Curves (`cubic-bezier(0.16, 1, 0.3, 1)`)
- **Effects**: HTML5 Canvas Particle Engine, Canvas Confetti
- **Icons**: Lucide React
- **Deployment**: GitHub Pages (Dual-supported: `gh-pages` branch & GitHub Actions)
